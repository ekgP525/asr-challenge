## Challenge Description 요약

야외 잡음 속에서 한국어 음성을 실시간으로 받아쓸 때, 잡음이 인식 정확도와 응답 지연을 **함께** 어떻게 무너뜨리는지 평가하는 챌린지입니다. 공개 한국어 코퍼스(Zeroth-Korean, FLEURS ko_kr) 424발화에 FSD50K의 야외 잡음(군중·바람·차량·행사)을 SNR 20/10/5/0 dB로 합성한 2,120개 평가 파일을 공개하고, 모든 시스템을 같은 VAD 설정의 스트리밍 시뮬레이터(0.5초 청크, 가상 시계)에서 측정합니다. 순위는 잡음 4조건 평균 CER이며, 4조건 각각에서 p90 최종 지연이 1.0초를 넘으면 순위 밖으로 둡니다. 정확도 외에 종료 검출 오차, 조기 절단율, 부분결과 수정률, 발화 전 부분결과율, RTFx를 함께 보고해 잡음에 따른 정확도–지연 이동 경로를 제시합니다.

## Method 요약

Qwen3-ASR 1.7B·0.6B를 추가 학습 없이 오프라인·스트리밍 2×2로 교차한 네 베이스라인(B1~B4)을 vLLM 백엔드, NVIDIA L4에서 측정했습니다. 평가 코드(정규화기, CER, 스트리밍 시뮬레이터, 지연·종료 검출·수정률 지표, 리더보드 생성)와 평가셋 생성 스크립트(FSD50K 라이선스 필터, ITU-T P.56 레벨 기준 SNR 합성)를 모두 공개하고, Colab 노트북 하나로 다운로드부터 리더보드까지 재현됩니다.

## 참고 사항

- 지연 측정은 실제 재생 대신 가상 시계(청크 도착 시각 + 실측 처리 시간)를 쓰므로 실행 시간이 연산 시간뿐이며, 발화당 1회 측정하고 B2 40발화 3회 반복으로 흔들림을 보고합니다(차이 중앙값 ?? ms).
- VAD 게이트: 엔드포인터가 발화 시작을 잡은 뒤에야 ASR에 오디오를 넘깁니다. 게이트 없이 흘려 넣으면 Qwen3-ASR 스트리밍이 발화 전 구간에서 환각한 문장을 접두부로 고정해 발화 전체가 틀리는 현상을 확인했습니다.
- 데이터는 모두 재배포 가능한 공개 자료만 사용했습니다(Zeroth CC BY 4.0, FLEURS CC BY 4.0, FSD50K CC0·CC BY 클립). AI Hub 자료는 재배포 금지라 쓰지 않았습니다.
- 모델·추론 코드 출처: Qwen3-ASR (QwenLM), qwen-asr 0.0.6, vLLM 0.14.0, Silero VAD.
