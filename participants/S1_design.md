# S1 설계 기록: 적응형 엔드포인터 (2026-11-06, 오프라인 실험)

모든 수치는 GPU 없이 로컬(M4)에서 `evaluation/endpointer_eval.py`로 엔드포인터만 돌리고, `evaluation/endpointer_whatif.py`로
기록된 B4(0.6B 스트리밍) 실행에 투영한 **추정치**다. 재생된 부분결과는 1.0 s 간격(B4 설정)이라 텍스트 신호가 실제 S1(0.5 s 디코드 청크)보다
늦게 도착하는 비관적 조건이다. 실제 수치는 Colab L4 실행으로 확정한다.

## 출발점: 베이스라인에서 지연과 CER이 어디서 생기나

| 사실 | 수치 (B4, 기록) | 의미 |
|---|---|---|
| 0 dB 종료 검출 지연의 중앙값은 clean과 거의 같다 | p50 0.51 → 0.58 s | 잡음이 평균적으로 느리게 만드는 게 아니라 **꼬리**가 문제 |
| 꼬리는 군중(crowd) 잡음에 집중 | crowd p90 2.40 s, 나머지 0.84~0.94 s | 사람 말소리 잡음이 Silero 확률을 0.5~0.8에 묶어 둠 |
| 종료 후 처리 시간은 조건과 무관 | p90 0.15 s | 지연 예산 = 1.0 − 종료 검출 지연 p90 − 0.15 |
| 조기 절단은 문장 내 500 ms 이상의 쉼에서 생김 | clean 43개, 남은 발화 중앙값 6.0 s | 절단 발화 CER 66~75%가 전체 CER의 큰 몫 |
| 정답 문장의 90%가 "다"로 끝남 | 다 380 / 요 18 / 죠·까 각 4 | 부분결과로 문장 완결 여부를 판정할 수 있음 |

## 실패한 시도: 에너지 게이트

"Silero가 음성이라 해도 에너지가 잡음 바닥 근처면 무음" 규칙. 0 dB에서는 말소리 자체가 바닥 에너지와 겹쳐 발화 중간에 끊긴다
(조기 절단 0 dB 48~71%). 꼬리도 못 줄였다(babble 에너지도 요동). 폐기.

## 효과가 있는 것 1: 종료 임계값 상향

Silero VADIterator는 시작 임계값 t, 종료 히스테리시스 t−0.15를 쓴다. 시작은 0.5로 두고(ASR 게이트와 부분결과가 베이스라인과 동일), **종료만**
"음성 ≥ 0.8이면 타이머 리셋, < 0.65면 무음"으로 올린다. 발화 시작 직후 0.8을 한 번 넘기 전까지는 기본 히스테리시스를 유지해 약한 시작부가 끊기지 않게 한다.

## 효과가 있는 것 2: 부분결과로 무음 길이 조절

최신 부분결과가 문장 종결 어미(다/요/까/죠/네/군/라/자/오/냐/는가/련/지)로 끝나면 500 ms, 아니면 700 ms를 기다린다.
"불완전하면 기다린다"는 방향이라 지연이 늘지만, 500 ms 넘는 문장 내 쉼의 대부분을 살린다.

- 임계값 상향만(V1)은 제약을 넉넉히 통과하지만 CER이 나빠진다(0 dB 조기 절단 64→97).
- 텍스트 규칙만(V5)은 절단을 가장 많이 줄이지만 꼬리 지연을 못 잡는다.
- 둘을 합친 V2b가 제약 안에서 CER이 가장 낮다. 0 dB 여유가 24 ms로 좁으므로 실제 실행에서는 0.5 s 디코드 청크로 텍스트 지연을 줄인다.
- 같은 엔드포인터를 1.7B(B2)에 얹으면 CER 추정 14.11이지만 종료 후 처리가 길어 0 dB p90 1.10 s로 제약을 넘는다 → S2는 비교용.
