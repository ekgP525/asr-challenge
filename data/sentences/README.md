# 캠퍼스 도메인 문장

4개 영역, 약 200문장. 각 파일은 탭 구분: `문장<TAB>출처 URL`.

| 파일 | 영역 | 목표 문장 수 |
|---|---|---|
| `academic.tsv` | 학사 규정 (휴학·복학·재수강·학사경고·졸업요건) | 50 |
| `admin.tsv` | 행정 절차 (증명서·휴학·장학·등록금) | 50 |
| `international.tsv` | 외국인 학생 행정 (비자·외국인등록·기숙사) | 50 |
| `facility.tsv` | 캠퍼스 시설 (건물·도서관·학생회관) | 50 |

- 숫자는 한글 표기로 적는다 (`evaluation/normalizer.py` 규칙 참고).
- 출처는 아주대학교 공개 홈페이지(학사 규정·생활 안내 페이지)만 사용한다.
