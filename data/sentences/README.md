# 캠퍼스 도메인 문장 (200문장)

마스코트 동상 앞 음성 비서에게 학생이 실제로 물어볼 법한 질의를 4개 영역 × 50문장으로 작성.
각 파일은 탭 구분 `문장<TAB>출처 URL`, `#`로 시작하는 줄은 주석.

| 파일 | 영역 | 문장 수 | 주요 출처 |
|---|---|---|---|
| `academic.tsv` | 학사 규정 (휴·복학, 제적·재입학, 졸업·조기졸업·졸업유예, 복수·부·마이크로전공, 수강신청·정정, 파란학기) | 50 | 학사지원 > 학적/졸업/교육과정 페이지, 수강신청·수강정정 공지, 파란학기제 소개 |
| `admin.tsv` | 행정 절차 (증명서 발급, 등록금 납부·환불, 교내·국가장학, 학자금대출, 학생증) | 50 | 증명서 발급 안내, 등록/환불 공지, 장학 안내, 학생증 안내 |
| `international.tsv` | 외국인 유학생 행정 (외국인등록, 비자 변경·연장, 시간제취업, 학비·장학, 기숙사·보험, 어학연수) | 50 | 외국인 입학 > 비자 발급 및 체류관리, 학비 안내, 국제교육센터 생활안내 |
| `facility.tsv` | 캠퍼스 시설 (건물별 편의시설·식당·카페, 도서관, 보건진료소, 종합지원센터, 주차, 생활관) | 50 | 편의시설 안내, 도서관 출입/배석, 학생서비스, 주차 공지, 생활관 |

## 작성 규칙

- 출처는 아주대학교 공개 홈페이지(ajou.ac.kr 하위)만 사용하고, 문장은 해당 페이지에 실제로 있는 제도·시설·절차를 묻도록 작성했다. 문구는 복사하지 않고 구어체 질문으로 새로 썼다.
- 숫자는 한글로 적는다(`이십사시간`, `사분의 일`, `삼십일`). `evaluation/normalizer.py` 규칙상 아라비아 숫자는 한자어 읽기로만 변환되므로, 고유어 숫자(세 학점 등)는 피했다.
- 비자 코드(D-2, D-4)처럼 영문+숫자 표기는 정답 표기가 모호해 `유학비자`, `어학연수 비자`로 풀어 썼다.
- 모든 문장은 `data/terms.txt`의 용어를 1개 이상 포함하고, 사전의 모든 용어는 최소 1개 문장에 등장한다.

## 검증

```bash
python data/scripts/check_sentences.py
```

형식 오류, 아라비아 숫자, 중복, 정규화 불안정, 용어 미포함 문장, 미사용 용어를 보고한다.
